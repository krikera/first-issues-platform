2. **analytics.png** - Analytics dashboard
   - Show the statistics and charts
   - Display repository trends
   - Recommended size: 1200x800px

## How to Take Screenshots

1. Open https://your-domain.com in your browser
2. Use browser DevTools to set viewport to 1200x800 (for consistency)
3. Take screenshots using:
   - Mac: `Cmd + Shift + 4` (select area)
   - Windows: `Win + Shift + S`
   - Linux: `Screenshot` tool or `gnome-screenshot -a`
4. Save as PNG format
5. Name files exactly as: `search.png` and `analytics.png`

## Tips

- Use light mode for better visibility
- Ensure UI is in a clean state (no loading spinners)
- Show actual data/results if possible
- Avoid showing personal information
